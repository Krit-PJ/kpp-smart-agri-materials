ที่อยู่ API

กำลังโหลด…
ทุกคำขอเป็น GET พร้อมพารามิเตอร์ api=v1 และ endpoint · ต้องแนบ key เมื่อผู้ดูแลระบบเปิด "ต้องใช้ API Key" (ขอ Key ได้จาก Super Admin ที่เมนู ตั้งค่ารายงานและระบบ → Data API)
Key ที่ใส่ในหน้าเว็บฝั่งผู้ใช้ (JavaScript) ทุกคนเปิดดูได้ ใช้ Key เพื่อ แยกและยกเลิกสิทธิ์รายเว็บไซต์ ไม่ใช่เพื่อปกป้องข้อมูลลับ · จำกัด 120 ครั้ง/นาที/Key · Google Apps Script ตอบประมาณ 1–3 วินาที ควรโหลดข้อมูลเป็นระยะ (เช่น ทุก 5–15 นาที) ไม่ใช่ทุกวินาที

Endpoint

meta

ข้อมูลอ้างอิง: ชื่อหน่วยงาน ปี ครั้งที่ปัจจุบัน รายการรอบรายงาน (วันเริ่ม/สิ้นสุด/กำหนดส่ง) 11 อำเภอ (รหัส D01–D11 และรหัสอำเภอ 6201–6211 สำหรับจับคู่แผนที่) และตัวชี้วัดทุกข้อ

summary

ยอดรวมจังหวัด ณ ครั้งที่เลือก: ยอดครั้งนี้ (week) ยอดสะสม (cumulative) แยกรายอำเภอ (by_district) จำนวนอำเภอที่ส่งแล้ว สถานะการส่ง และกิจกรรมข้อ 4

districts

ยอดรายอำเภอ (ทั้ง 11 อำเภอ หรือระบุ district) พร้อมสถานะการส่ง (none / draft / submitted / accepted / returned) และ late (ส่งหลังกำหนด)

timeseries

อนุกรมเวลาตั้งแต่ยอดยกมา (ครั้งที่ 0) ถึงครั้งที่เลือก ระดับจังหวัด หรือระบุ district เหมาะกับกราฟเส้นแนวโน้ม

status

ตารางสถานะการส่งรายงาน อำเภอ × ครั้ง (ไม่มีชื่อผู้ส่ง)

พารามิเตอร์

ชื่อค่าคำอธิบาย
apiv1เวอร์ชันของ API (จำเป็น)
endpointmeta summary districts timeseries statusค่าเริ่มต้น summary
keykpp_…API Key (จำเป็นเมื่อเปิด "ต้องใช้ API Key")
roundตัวเลข หรือ currentครั้งที่รายงาน ค่าเริ่มต้น = ครั้งปัจจุบัน · 0 = ยอดยกมา
itemsagri all หรือ R29,R31ตัวชี้วัด ค่าเริ่มต้น agri = ข้อ 2.2 พื้นที่เกษตร (R29 ส่งเสริม/อบรม · R30 แปรรูป · R31 ไถกลบ · R32 อื่น ๆ) ดูรหัสทั้งหมดได้จาก meta
districtD01–D11เฉพาะ districts และ timeseries
formatjson csvCSV (UTF-8) ใช้กับ Excel / Google Sheets ได้ทันที
callbackชื่อฟังก์ชันJSONP สำหรับเว็บที่เรียกข้ามโดเมนแบบเก่า
