# KPP Smart Agri-Materials

**ระบบรายงานการจัดการเศษวัสดุทางการเกษตร แบบสะสมรายสัปดาห์ — สำนักงานเกษตรจังหวัดกำแพงเพชร**

เว็บไซต์: https://krit-pj.github.io/kpp-smart-agri-materials/
ฐานข้อมูล: Google Sheet “KPP Smart Agri-Materials — ฐานข้อมูลรายงานเศษวัสดุการเกษตร” ในโฟลเดอร์ Google Drive “6. รายงาน ปภ. เศษวัสดุทางการเกษตร”

```
 เจ้าหน้าที่ 11 อำเภอ ──┐                         ┌── Google Apps Script (Web App) ── Google Sheet (ฐานข้อมูล)
 ผู้รวบรวมระดับจังหวัด ──┼──  GitHub Pages (docs/) ─┤        กฎของระบบชุดเดียวกัน: docs/assets/js/server.js
 ผู้ดูแลระบบ ────────────┘                         └── โหมดทดลอง (ยังไม่ตั้ง API_URL): ข้อมูลตัวอย่างในเบราว์เซอร์
```

## ความสามารถ

| เรื่อง | รายละเอียด |
|---|---|
| แผนที่ภาพรวม (Smart Map) | แผนที่ 11 อำเภอ ระบายสีตามยอดสะสม เลือกครั้งที่/ตัวชี้วัด/แผนที่พื้นหลัง คลิกอำเภอเพื่อดูตัวเลข |
| กรอกรายงาน 3 ขั้น | 1 กรอกข้อมูล → 2 ตรวจสอบ (ระบบเตือนค่าผิดปกติ/ข้อมูลไม่ครบ) → 3 ยืนยันและส่ง · บันทึกร่างได้ · กู้คืนข้อมูลที่กรอกค้างในเครื่อง |
| นับสะสมอัตโนมัติ | ยอดสะสม = ยอดยกมา + ทุกครั้งที่ “ส่งแล้ว/ตรวจรับแล้ว” · ช่องว่างไม่นับ · ส่งซ้ำ = แทนที่ (ไม่ซ้ำ) · ข้อ 3.5/3.6 “ณ ครั้งที่รายงาน” ใช้ค่าล่าสุด · ข้อ 4 กิจกรรมอื่นยกไปครั้งถัดไปเอง |
| ตรวจรับ | จังหวัด “ตรวจรับ” หรือ “ส่งกลับแก้ไข” พร้อมหมายเหตุ อำเภอเห็นหมายเหตุทันที |
| สถานะการส่งรายงาน | ตารางอำเภอ × ครั้ง (ส่งแล้ว/ตรวจรับ/ร่าง/ส่งกลับ/เลยกำหนด/ส่งช้า) · คัดลอกข้อความแจ้งเตือน LINE · **ค่าเริ่มต้นเห็นเฉพาะจังหวัด** มีสวิตช์เปิดให้อำเภอดูได้ |
| พิมพ์รายงานตามแบบฟอร์ม | ตามแบบ ปภ. 2 หน้า (สีหัวตาราง ช่องเทา การรวมช่อง ลายเซ็น QR) เลือกครั้งที่ แก้ไข **ปี / ครั้งที่ / ระหว่างวันที่–ถึงวันที่ / เลขหนังสือสั่งการ / ผู้รายงาน / QR Code** ได้ คลิกแก้ข้อความในตารางก่อนพิมพ์ได้ · A4 หรือ Letter · บันทึกเป็น PDF |
| ส่งออก | Excel ตามแบบฟอร์มเดิม (ระดับจังหวัดมีชีต “แยกรายอำเภอ”) · CSV |
| บันทึกการเข้าใช้งาน | ทุกการเข้า/ออกระบบ เข้าระบบไม่สำเร็จ ลงทะเบียน บันทึก/ส่ง/ถอน/ตรวจรับ พิมพ์ ส่งออก จัดการผู้ใช้ ตั้งค่า พร้อมอุปกรณ์ที่ใช้ ค้นหา/กรอง/ดาวน์โหลด CSV |

## ระดับผู้ใช้

| ระดับ | เข้าสู่ระบบ | ทำอะไรได้ |
|---|---|---|
| **Admin — เจ้าหน้าที่อำเภอ** | ลงทะเบียนเอง (คำนำหน้า ชื่อ-สกุล ตำแหน่ง อำเภอ เบอร์โทร) แล้ว **ใช้งานได้ทันที** · ครั้งต่อไปใช้ **หมายเลขโทรศัพท์** อย่างเดียว | กรอก ตรวจสอบ ยืนยัน ส่ง แก้ไข/ถอน **เฉพาะอำเภอตนเอง** · ดูรายงานและพิมพ์ของอำเภอตนเอง · ดูสถานะการส่งเมื่อจังหวัดเปิดสวิตช์ |
| **Mini Super Admin — ผู้รวบรวมระดับจังหวัด** | ชื่อผู้ใช้ + รหัสผ่าน (Super Admin สร้างให้) | สรุปผลทั้งจังหวัด ตรวจรับ/ส่งกลับแก้ไข สถานะการส่ง พิมพ์/ส่งออกรายงานจังหวัด ตั้งรอบรายงานและหัวรายงาน ระงับ/เปิดบัญชีอำเภอ ดูบันทึกการใช้งาน (ยกเว้นของ Super Admin) |
| **Super Admin — ผู้ดูแลระบบสูงสุด** | ชื่อผู้ใช้ + รหัสผ่าน | ทุกอย่าง + **เพิ่ม/ลบ Mini Super Admin** แก้ไขบทบาท/รหัสผ่านผู้ใช้ แก้ไขรายงานทุกอำเภอแม้รอบปิด ตั้งค่าการลงทะเบียน/แผนที่สาธารณะ/อายุการเข้าสู่ระบบ |

บัญชี Super Admin เริ่มต้นสร้างไว้แล้วในชีต `Users` (ชื่อผู้ใช้ `Krit`) รหัสผ่านเก็บแบบเข้ารหัส (SHA-256 + salt) — แนะนำให้เปลี่ยนรหัสผ่านที่เมนู **ข้อมูลส่วนตัว** หลังเข้าใช้ครั้งแรก

## ติดตั้งส่วนเชื่อมฐานข้อมูล (ครั้งเดียว ~10 นาที)

Google Sheet ฐานข้อมูลสร้างและใส่ข้อมูลตั้งต้นไว้แล้ว (11 อำเภอ, รอบรายงาน 26 สัปดาห์, บัญชี Super Admin) เหลือขั้นตอนที่ต้องทำด้วยบัญชี Google เจ้าของไฟล์:

1. เปิด Google Sheet ฐานข้อมูล → เมนู **ส่วนขยาย → Apps Script**
2. ลบโค้ดตัวอย่างใน `Code.gs` แล้ววางเนื้อหาไฟล์ [`apps-script/KPP-AllInOne.gs`](apps-script/KPP-AllInOne.gs) ทั้งไฟล์ (หรือวาง `Code.gs` + สร้างไฟล์ `Lib.gs` แยก) → กดบันทึก
3. **การตั้งค่าโปรเจกต์** (รูปเฟือง) → เขตเวลา `(GMT+07:00) Bangkok`
4. เลือกฟังก์ชัน `setup` → **เรียกใช้** → อนุญาตสิทธิ์ (ตรวจโครงสร้างชีต/สร้างกุญแจเข้ารหัส ไม่ลบข้อมูลเดิม)
5. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน**
6. คัดลอก URL ที่ลงท้าย `/exec` ไปใส่ใน [`docs/assets/js/config.js`](docs/assets/js/config.js)
   ```js
   API_URL: 'https://script.google.com/macros/s/xxxxxxxx/exec',
   ```
   (แก้บน GitHub ได้โดยตรง: เปิดไฟล์ → ไอคอนดินสอ → Commit) รอ 1–2 นาที เว็บจะเชื่อมฐานข้อมูลจริง

> แก้โค้ด Apps Script ภายหลัง: **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชัน: ใหม่** URL เดิมใช้ต่อได้

ก่อนตั้ง `API_URL` เว็บจะเปิดใน **โหมดทดลอง** (มีข้อมูลตัวอย่าง เก็บในเบราว์เซอร์เท่านั้น) ใช้ทดลอง/อบรมได้ · บัญชีทดลอง: อำเภอ `0810000001`–`0810000011` · จังหวัด `mini`/`mini1234` · Super `admin`/`admin1234` · เปิดโหมดทดลองบนระบบจริงได้ด้วยการต่อท้ายลิงก์ `?demo=1`

## ชีตในฐานข้อมูล

| ชีต | เก็บอะไร |
|---|---|
| `Settings` | หัวรายงาน ปี เลขหนังสือสั่งการ QR Code ผู้รายงานระดับจังหวัด สวิตช์ต่าง ๆ |
| `Districts` | 11 อำเภอ (รหัส D01–D11 ตามรหัสอำเภอ 6201–6211) |
| `Users` | ผู้ใช้ทุกระดับ (เบอร์โทร/ชื่อผู้ใช้ รหัสผ่านเข้ารหัส บทบาท สถานะ เข้าใช้ล่าสุด) |
| `Rounds` | รอบรายงานรายสัปดาห์ (ครั้งที่ 0 = ยอดยกมา) วันเริ่ม/สิ้นสุด/กำหนดส่ง เปิด–ปิดรับ |
| `Data` | รายงาน 1 แถว = 1 อำเภอ × 1 ครั้ง (สถานะ, ผู้ส่ง, ผู้ตรวจ, ค่าแต่ละข้อ) |
| `AccessLog` | บันทึกการเข้าใช้งานและการดำเนินการทั้งหมด |

แนะนำ: ตั้งค่าให้ Google Sheet นี้แชร์เฉพาะผู้ดูแล (ข้อมูลเบอร์โทรอยู่ในชีต) ส่วนผู้ใช้ทั่วไปใช้ผ่านเว็บไซต์เท่านั้น

## ความปลอดภัยและข้อควรทราบ

- การเข้าสู่ระบบของอำเภอด้วยเบอร์โทรอย่างเดียวตามที่กำหนด สะดวกแต่ผู้ที่รู้เบอร์สามารถเข้าแทนได้ ระบบจึงมี: บันทึกการเข้าใช้งานทุกครั้ง, จำกัดการลองผิด 8 ครั้ง/15 นาที, ระงับบัญชี/บังคับออกจากระบบได้ทันที, สิทธิ์จำกัดเฉพาะอำเภอตนเอง และ Super Admin ปิดการลงทะเบียนเองได้เมื่อมีบัญชีครบ
- บัญชีระดับจังหวัดใช้ชื่อผู้ใช้/รหัสผ่าน รหัสผ่านไม่ถูกเก็บเป็นข้อความ
- โทเคนเข้าสู่ระบบลงนามด้วย HMAC-SHA256 หมดอายุตาม `SESSION_HOURS` (ค่าเริ่มต้น 12 ชั่วโมง)
- แผนที่สาธารณะแสดงเฉพาะยอดรวมของรายงานที่ส่งแล้ว ไม่มีชื่อ/เบอร์โทร ปิดได้ที่ **ตั้งค่า → การเข้าถึงข้อมูล**

## สำหรับผู้พัฒนา

```
docs/                     หน้าเว็บ (GitHub Pages เผยแพร่จากโฟลเดอร์นี้)
  assets/js/items.js      ตัวชี้วัดตามแบบฟอร์ม (แถว Excel, ความสูงแถว, สีช่อง)
  assets/js/core.js       ตรรกะยอดสะสม (ใช้ร่วม Apps Script/เว็บ/ทดสอบ)
  assets/js/server.js     กฎของระบบทั้งหมด: สิทธิ์ การส่ง/ตรวจรับ ผู้ใช้ บันทึกการใช้งาน
  assets/js/print.js      แบบรายงานสำหรับพิมพ์
  assets/template.xlsx    แบบฟอร์ม Excel ต้นฉบับ (ใช้ส่งออก)
apps-script/              Code.gs (เชื่อม Google Sheets) + Lib.gs (สร้างจาก docs/assets/js)
tools/build-gs.js         สร้าง Lib.gs / KPP-AllInOne.gs
tests/                    ทดสอบกฎของระบบ, Apps Script จำลอง, หน้าเว็บทุกบทบาท, เทียบแบบพิมพ์กับ PDF ต้นฉบับ
```

```bash
node tools/build-gs.js            # ทุกครั้งที่แก้ items/core/server.js
cd tests && npm install && npm test
python3 tests/ui_test.py /tmp/shots     # ต้องมี playwright
```
